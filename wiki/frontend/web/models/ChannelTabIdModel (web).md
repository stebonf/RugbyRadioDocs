# ChannelTabIdModel (web)

## Sintesi

Type alias locale per identificare i tab della pagina canale pubblico.

## Proprietà

- `value` (`'radio' | 'matches' | 'teams' | 'tables' | 'share'`) - obbligatoria; valore tab selezionabile.
