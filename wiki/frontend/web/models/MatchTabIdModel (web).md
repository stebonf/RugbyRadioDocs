# MatchTabIdModel (web)

## Sintesi

Type alias locale per identificare i tab della pagina match pubblico.

## Proprietà

- `value` (`'events' | 'lineup_home' | 'lineup_away' | 'stats' | 'share'`) - obbligatoria; valore tab selezionabile.

## Origine dati

Stato locale di [[GMatchPage (web)]].

## Consumer FE

- [[GMatchPage (web)]]

## API correlate

Non deducibile.
