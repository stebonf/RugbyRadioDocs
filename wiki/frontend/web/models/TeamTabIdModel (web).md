# TeamTabIdModel (web)

## Sintesi

Type alias locale per identificare i tab della pagina team pubblico.

## Proprietà

- `value` (`'team' | 'players' | 'matches' | 'share'`) - obbligatoria; valore tab selezionabile.

## Origine dati

Stato locale di [[GTeamPage (web)]].

## Consumer FE

- [[GTeamPage (web)]]
