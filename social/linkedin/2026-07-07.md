AI Isn't Building Rugby Radio Live. It's Building It With Me.

One of the biggest misconceptions about AI-assisted development is that you simply ask an LLM to write some code.

That's not how I build Rugby Radio Live.
AI has become part of almost every stage of the project.
Not just coding.

It helps me:
📋 Analyze requirements
🏗 Challenge architectural decisions
🎨 Explore UI ideas
🧪 Prototype new features
📝 Produce documentation
🔍 Review implementations

Each AI has a different role.
Some act like software architects.

Others behave like functional analysts or developers.
The interesting part isn't replacing software engineering.
It's creating a development workflow where AI continuously challenges your own thinking.

In many cases, the biggest value isn't the code it writes.
It's the questions it forces you to ask before writing the code yourself.
That's becoming one of the most interesting parts of this project.
