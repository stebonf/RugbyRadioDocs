## Note finali

- Limiti dell'analisi:
  - L'analisi e limitata ai soli file modificati dopo il 2026-05-14.
  - I template e gli stili collegati sono indicati dai decorator, ma non analizzati in profondita.
  - I componenti child importati sono elencati come dipendenze immediate, non censiti come pagine.
- Elementi non deducibili:
  - API backend effettive chiamate dai service frontend.
  - Workflow correlati.
  - Asset completi dentro template/stili non analizzati.
  - Eventuali route runtime generate da server o deploy.
- Possibili approfondimenti:
  - Eseguire helper service-map frontend per dedurre API backend tramite i service.
  - Eseguire helper senza filtro temporale per mappa completa delle pagine.
