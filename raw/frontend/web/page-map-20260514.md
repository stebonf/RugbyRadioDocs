### Route

- Path: `/g-match/:matchId`
- Parametri: `matchId`
- Guard/resolver: nessuno (pubblica)

### Selector o entrypoint

`app-g-match`

### Responsabilità

Pagina pubblica di dettaglio partita (viewer/spettatore). Estende `GBaseUserComponent`. Tab interface: Events (feed telecronaca + commentatore), Lineup Home/Away, Stats, Share. Polling automatico per aggiornamento partita in corso. Gestisce follow, like, login callback.

### Componenti usati

- `MatchHeaderComponent`
- `GMatchEventsComponent` — eventi + commentatore
- `MatchLineupComponent` (×2) — formazioni
- `MatchStatsComponent`
- `EntityShareComponent`
- `EntityTabsComponent`
- `EntityScrollToTopComponent`

### Servizi frontend usati

- `MatchService` — `getMatch()`, `likeMatch()`, `manageFollow()`
- `ChannelService` — dati canale associato
- `BlogService` — `getMatchBlog()`
- `LoginCallbackService` — redirect login
- `AnalyticsService`, `LoggingService`

### Modelli FE o DTO usati

- `matchDto`, `blogDto`

### API backend dipendenti

- `MatchesV1Controller.GetMatchById` — GET `/matches/{matchId}` (MTC-02)
- `BlogV1Controller.GetMatchBlog` — GET `/blog/matches/{matchId}` (BLOG-02)
- `MatchesV1Controller.SaveLike` — PUT `/matches/{matchId}/like` (MTC-13)
- `MatchesV1Controller.ManageFollow` — PUT `/matches/{matchId}/follow` (MTC-15)

### Stati UI

- Loading
- Stato partita: `isStarted`, `isHalfTime`, `isFullTime`
- Tab selezionata (`selectedTab`: `'events' | 'lineup_home' | 'lineup_away' | 'stats' | 'share'`)
- Scroll to top (`showScrollTop`)
- Copia link (`hasCopiedLink`)
- Polling attivo (Subscription)
