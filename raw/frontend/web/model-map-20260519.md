### Nome wiki suggerito

### File sorgente

### Tipo

Interface

### Sintesi tecnica

Interface usata dal frontend per aggiornare title, meta tag, canonical, Open Graph, Twitter card e structured data della pagina.

### Proprietà

- `title` (`string`) - Obbligatorieta: obbligatoria. Titolo pagina passato a `Title.setTitle`.
- `description` (`string`) - Obbligatorieta: opzionale. Meta description e descrizione Open Graph/Twitter.
- `canonicalUrl` (`string`) - Obbligatorieta: opzionale. URL canonical gestito tramite `link[rel="canonical"]`.
- `imageUrl` (`string`) - Obbligatorieta: opzionale. Immagine per Open Graph e Twitter.
- `type` (`string`) - Obbligatorieta: opzionale. Tipo Open Graph, fallback `website`.
- `siteName` (`string`) - Obbligatorieta: opzionale. Site name Open Graph, fallback `Rugby Radio Live`.
- `locale` (`string`) - Obbligatorieta: opzionale. Locale Open Graph.
- `twitterCard` (`'summary' | 'summary_large_image'`) - Obbligatorieta: opzionale. Tipo Twitter card.
- `structuredData` (`SeoStructuredData | SeoStructuredData[]`) - Obbligatorieta: opzionale. JSON-LD inserito nel documento.
